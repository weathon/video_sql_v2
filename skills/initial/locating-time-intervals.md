# Introduction

Temporal questions require locating anchor events before measuring or inspecting the target interval.

# When to use

Use it for relative chronology, duration, transitions, and sparse clues separated in time.

# Main content

Locate each anchor independently and record candidate times. Confirm anchors from precise rows before applying MIN, MAX, ordering, or interval arithmetic. Search a narrow neighborhood first and expand only when evidence indicates that the boundary lies outside it. Distinguish an event's first mention from its actual start and a summary's scope from the evidence time. For questions spanning two anchors, establish both endpoints before counting or calculating duration.
