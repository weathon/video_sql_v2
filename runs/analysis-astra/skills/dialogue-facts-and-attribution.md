# Introduction

对话问题通常由一小段明确原话解决，但需要正确的说话者、时态和语义角色。

# When to use

问题询问说了什么、谁建议、某词是什么意思、选择标准、分工类别或原本打算做什么时使用。

# Main content

1. 以独特词、数字或行动线索检索 episode，再按真实 ID 读取完整局部对话。
2. 保留说话者—陈述的直接关系。提到一个选项、回忆一个选项和首次提出建议是不同动作。
3. 区分准备、想买、忘记购买和实际取得。回答意图问题使用意图陈述，回答完成问题则寻找完成证据。
4. 问题附带衣着描述时，先找到明确对话，再用同窗视觉证据绑定说话者；不要反复用没有索引的衣着词搜索文本。
5. 完整保留问题要求的并列项目、限定词和类别。不要无依据地将多个具名成分压成一个修饰语，也不要添加与问题无关的购买项。
6. 原话已足够时直接作答。仅为无关姓名、衣着或背景继续检索可能引入额外错误。
