# Introduction

“有人看视频”“出现付款界面”和“已经识别具体应用或金额”是不同证据层级。

# When to use

答案要求品牌、应用名称、打印字样、屏幕值、标签集合或精确小数时使用。

# Main content

1. 先用行为和对话定位正确物体与时刻，再检索同窗文字、可能的别名及直接标签。
2. 对视觉证据检查清晰、稳定的局部片段，要求辨认实际文字或标志。界面颜色、横屏视频、相似包装和邻近话题不足以确定名称。
3. 问句不提供偏爱的标签作为提示。先确认可读字符或诊断特征，再与候选比较。
4. 需要转录时保留源文字、材料限定和精确数字；仅在问题要求时附译义。对话中的称呼与印刷标签分别记录。
5. 原始应付金额、后续取整金额、输入金额和完成付款值分别检索；不可为不可读的小数补位。
6. 画面只支持大类时按该粒度报告，或标记具体名称未知。不要依据评分差异反推未观察到的品牌或词形。
