# Introduction

视觉核验用于解决明确的可见证据缺口，而不是在大段视频中寻找一个猜测事件。

# When to use

文字已定位候选，但不能确认衣着、物体、动作边界、空间关系、文字或数量时使用。

# Main content

1. 先确定片段和一个具体未决条件，再调用 `clip_qa`。提问保持中性，不预置品牌、颜色、数量或动机。
2. 使用正确的全局秒数，明确指定 fps，选择包含必要前后状态的最小区间。短暂开箱、交接、投放或越过门槛通常需要更密集的相邻帧。
3. 较高 fps 用来辨别动作，不会自动提高整段总数的可靠性，也不应把连续动作拆成更多微事件。
4. 图片最高为 854×480。采样需满足图像预算；超预算时显式缩短窗口或调整 fps。长活动按有意义的阶段分段，不传入超过 20 分钟的窗口。
5. 先问物体的开放式外观或动作，再判断候选类别。避免用“是不是某品牌”或强制几个猜测类别诱导识别。
6. 同一片段足以建立所需事实后，不继续进行无关衣着、姓名或屏幕核验。
