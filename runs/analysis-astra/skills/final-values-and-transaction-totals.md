# Introduction

报价、起拍价、修正值、付款口头讨论和实际完成交易的金额可能不同。

# When to use

问题询问原本打算支付多少、最后成交多少、赚了多少、买卖多少套，或多个项目合计时使用。

# Main content

1. 固定人物、物品集合、时间窗口和计量单位。区分件、套、包、交易笔数和货币数。
2. 每笔建立独立记录：物品实例、参与者、报价或计算、修改、最终确认、完成证据及来源。
3. 问原始金额时读取调整前计算；问实付或成交时使用最后明确确认的值。不可用较容易读取的取整值替代原始小数。
4. 竞价、玩笑数字和付款讨论不自动成为成交价。金额必须连到同一物品及成交动作；相似物品、混合展示页或邻近交接不能合并。
5. 所有必需分项都已确认后再求和，并在最终答案明确给出计算结果。单笔价格不能回答复数项目总额。
6. 屏幕不可读、最终修正未建立或单位冲突时，保留该分项未知，不用先前金额补齐。若问题问现场报出的总数，则转用现场报数技能。
