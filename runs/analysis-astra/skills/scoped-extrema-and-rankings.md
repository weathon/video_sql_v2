# Introduction

极值和排名只有在候选范围、度量及每个值的事件关系一致时才成立。

# When to use

问题询问谁最高、哪个最便宜、最多获得多少、各类最大值或排序时使用。

# Main content

1. 明确指标：单场得分、累计余额、单次取得数量、同时持有数量或最终成交价。相邻的另一指标不能替代。
2. 先建立题目指定阶段的起止边界，再枚举其中全部合格候选。后续同场地、同人物的活动可能已属于另一阶段。
3. 每个值绑定具体人物、物品实例和完成事件。若需要每类最大值，先分清各次独立事件，再按真实类别聚合。
4. 检索不能只覆盖最显眼候选，也不要用猜测数值过滤掉更大的未见值。优先排除其他活动中的无关数字。
5. 明确计算比较值并检查并列。最低值有多个候选时，逐一验证物品、主人和最终结果，不能从一个起拍价断言其他候选更贵。
6. 只有确认值进入正式排名；缺失项可能改变结论时保留不确定性，不制造精确名次。
