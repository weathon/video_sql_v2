# Introduction

多选题需要完整检验每个命题，而不是找到一个最清楚的答案后停止。

# When to use

问题询问哪些选项成立、哪些没有出现、哪些编号例外，或要求列出全部符合项时使用。

# Main content

1. 为每个选项记录其精确谓词、时间范围、来源行及状态：支持、反证、未决。保留句级证据，避免后续笔记将关键限定丢掉。
2. 指令和实际执行分别核验。要求用某物以及后来确实用了另一物，可能分别支持不同选项。
3. 精确词未命中时，检查行为改写、相关对象或已知前后锚点。若文字描述了行动却未命名活动，再做窄视觉分类。
4. 缺失或未出现的判断需要足够覆盖对应集合。低 fps 广扫、截断结果、有限 top-k 和 unknown 都不构成完整排除依据。
5. 标签缺失题固定对象和时刻，先建立已观察标签集；不要补全自然序列，也不要混入稍后其他对象的标签。
6. 编号事件建立逐项结果表，区分屏幕编号与发生顺序。一个显眼异常不代表只有一个异常。
7. 最终返回全部已支持项，保留重要未决项的状态；不要缩减为一个“最确定”的选择。
