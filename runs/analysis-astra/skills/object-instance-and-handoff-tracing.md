# Introduction

附近出现的同类物品、所有权对话和实际交接可能属于不同实例，需要逐段连接。

# When to use

问题询问谁的物品、谁交给谁、从哪里拿来，或稍后看到的物品由谁购买时使用。

# Main content

1. 将目标固定为具体实例，记录时间、外观、容器及可追踪位置。随后检索取出、持有、交出、接收和放下的连续过程。
2. 所有权判断应有同一实例的明确归属陈述或可解释的来源链。临时持有、坐在附近及物品第一次进入画面，不单独证明所有权。
3. 对交接同时记录提供者与接收者；后续赠送可能反转角色。不要仅凭“有人给巧克力”等共词片段回答相反方向的问题。
4. 对请求—取回问题，优先连接当时的请求、动作和来源。较晚的购买或物流记录只有明确指向同一物品时才相关。
5. 文字中的归属与视觉中的颜色或位置必须落在同一实例。若只证实了一个姓名和另一个可见物体，保留关联缺口。
6. 需要视觉核验时检查短而连续的交接过程，避免从交接前后相距很远的静态姿势推断。
