# Introduction

多粒度摘要、相邻字幕和重叠视频经常重复描述同一事件。正确总数首先依赖事件定义和完整范围。

# When to use

统计一天或一场活动中的访问、通话、往返、求助、表演、处理周期及其他重复事件时使用。

# Main content

1. 先定义一次合格事件及其主体、方向、阶段和完成条件。例如访问需要进入并参与，路过不一定算访问；一次取物往返可由目的—行动—返回区分。
2. 建立完整起止范围，按相邻时间段检索细记录，包含首尾候选和后续续段。不要把早期准备阶段或最后一组画面当成整个活动。
3. 使用包容性的行为措辞检索，避免只搜某一种说法而漏掉同义行动。不要预先按猜测数字过滤候选。
4. 每项记录时间、主体、对象、动作、完成证据和来源 ID。以稳定事件边界及跨窗口连续性去重，不同时累计链摘要和细行。
5. 只有独立完成的事件才递增。购买、提议、引用过去事件、同时可见的物体和重复字幕不是额外发生次数。
6. 对歧义项分别标记确认、重复、非目标和未决。若文本明确描述多次独立结果，可据此计数；只有具体缺口需要视频。
7. 最后核对台账是否覆盖全部请求范围，再汇总。匹配参考总数不能替代对组成项的核查。
