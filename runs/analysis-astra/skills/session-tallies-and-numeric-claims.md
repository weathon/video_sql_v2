# Introduction

明确总数有时比含糊逐项推算更可靠，但数字必须匹配问题的对象、范围和陈述性质。

# When to use

材料包含“总共”“我们有”“大约”或多种相邻数字，需决定是否直接采用时使用。

# Main content

1. 先判断问题要求复述参与者报数，还是测量实际发生的总量。
2. 找到数字的完整局部原话，确认说话者、单位、对象、场次及阶段，区分实际总数、指令、计划、单批数量、库存和估计。
3. 对无歧义且匹配范围的现场总数，可用相邻原始行确认后作答，不必从含糊视觉或竞价片段重建不可靠台账。
4. 若要求精确实测，而陈述是取整、自报或泛指日常情况，应结合独立事件证据核对。另一个人的数字不能转给目标人物。
5. 多个类型的分项数应分别核实再相加；不要把零散数字、工作站数量或一人一设备的猜测直接组成总数。
6. 原话总数与可确认分项不一致时，分别保留“说了多少”和“可计算多少”。不能为得到一个整齐结果而改写单位或补入缺项。
