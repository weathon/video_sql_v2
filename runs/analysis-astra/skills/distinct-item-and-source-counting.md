# Introduction

物理件数、款式数、试验类别数、来源数和动作次数对应不同集合。

# When to use

问题询问不同物品、类型、歌曲、来源容器、拍摄地点或安装类型的数量时使用。

# Main content

1. 明确集合单位及语义层级。某一轮需要区分的编号样品可以是题目中的类别；更粗的商品大类不必然是所问类别。
2. 给候选建立可追踪标识，记录所属物体、行动者、时间及必要属性。标签、图案和物理件分别处理。
3. 汇集整个活动内的候选，去重再次展示、重播、变体及重复处理。少数被点名的项目不自动构成完整集合。
4. 数某人的来源时，仅纳入该人实际从中取用的来源。桌上存在、被别人使用、对话提及或个人碗中的食物不单独构成新来源。
5. 数安装类型时，区分该人安装和本来就在场的设备；数地点事件时按问题的活动条件分类，不额外增加任意人数门槛。
6. 数字标签与字母标签必须绑定同一对象和时刻，不能把后来另一种容器的标记并入当前集合。
