# Introduction

场景中同时存在的事实并不自动构成原因。解释需要目标事件的触发条件、明确理由或可追踪的功能关系。

# When to use

问题询问为什么做、为什么停止、为何缺席、物品有何用途，或跨日行为为何反复发生时使用。

# Main content

1. 先定位确切动作、对象和人物，再读取决策点前后完整对话。立即触发原因、后续处理方式和最终结果分开记录。
2. 同时检验材料支持的竞争解释，例如修理与舒适调整、活动完成与电量中断。优先读取能区分解释的试用反馈、条件句、状态说明和续段。
3. 不以天气、忙碌姿态、附近设施、取物地点或后来做了什么直接填补动机。视觉核验可确认动作和状态，但通常无法单独证明意图、权限或行政原因。
4. 用途问题可追踪资源的实体事实链，并以稍后实际操作连接功能；附近谈论的另一项任务不自动解释该资源。
5. 解释跨日反复行为时，检索最初事件及紧随其后的明确反应，而不只收集后来的一般抱怨。
6. 媒体标签的原因可能来自配乐、歌词或屏幕文字。核验能承载该原因的模态；静帧或附近聊天没有提供声音原因时保留未知。
7. 明示原因直接陈述；仅有间接关系时标明推断。不要补充未建立的受益人、政策或后续成功情节。
