# Introduction

跨日问题需要每一天独立的局部证据，以及明确的比较口径或物品关联。

# When to use

问题询问两天活动有何不同、后来使用的东西何时由谁购买，或多天发生了多少次时使用。

# Main content

1. 分别限定每个日期并检索对应事件链，不依赖没有日期标签的综合 QA。
2. 比较出行、餐食或活动时，将决定、实际行动和完成对应起来。车辆在附近不证明乘坐，较早配送也不自动属于后来那顿饭。
3. 来源问题先定位后来的具体使用或展示，再追溯明确取得、入车、购买和交付记录。
4. 物品名称相同不足以证明跨日为同一实例。保留包装、数量、持有人或明确指代等连接证据；购买人、展示人和卖家也应分开。
5. 使用来源中最具体且已支持的类别，例如有明确叫车记录时保留其服务名称，不因外观另创一个排斥性分类。
6. 跨日事件计数应把每次完整进入—活动—离开或其他事件周期去重；后来提到旧事件不增加次数。
