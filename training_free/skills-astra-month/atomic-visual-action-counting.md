# Introduction

视觉动作次数应由符合固定标准的行为转换组成，不能直接累计手势、物体出现或整段模型报数。

# When to use

数量取决于短暂动作的开始、完成或重复边界时使用。

# Main content

1. 将问题中的一次动作写成可观察标准，例如实际释放、完成一次入口动作、一次连续展示或成功安装。标准必须保持一致。
2. 定位候选后，用短窗口和足够密的相邻帧检查动作前、过程中和完成后状态。不要依靠一段长视频的全局计数。
3. 为每次事件保留时间及完成证据。跨窗口延续的同一物品和动作只计一次；拾起、调整、蘸酱、低头或重新拿起不自动成为目标动作。
4. 若问题数吃完的独立份数，需要区分同一份多次咬食、短暂交接和真正的新份替换；若数咬食动作，则按该动作口径统计。
5. 更高采样密度用于判别边界，不应用来把一次连续设置或展示拆为多个微事件。
6. 不用最终台面库存补替未观察到的处理次数。发生 unknown、错误或冲突时，保留该候选状态并核查分歧窗口后再汇总。
