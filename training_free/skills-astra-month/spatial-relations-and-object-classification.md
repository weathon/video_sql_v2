# Introduction

文本中的“在旁边”“那里”和泛称物件，往往不能建立精确空间关系或物体类型。

# When to use

问题涉及里面、上面、某处位置、物品类别、设备类型或颜色时使用。

# Main content

1. 用文本锁定动作与目标实例，再看包含物体和参照物的局部画面。
2. 区分在容器上、旁边和内部；放在关闭的盖子上不等于进入容器。完成投入还需要观察实际进入过程。
3. 颜色判断说明对应部位，例如桶身与桶盖、设备主体与背景物。不同部位颜色不应造成无意义的标签冲突。
4. 相似设备分别分类，例如笔记本、独立显示器和陈列支架。计数前先统一类别边界。
5. 对短暂放下的物体检查动作发生时的外形与结构，不用较晚的摆放姿势或预设“杯／盘／碗”选项限定解释。
6. 尺寸或是否越过阈值需要可读测量、明确判定或足够清晰的关系证据；近似透视和后续行为不能替代测量。
