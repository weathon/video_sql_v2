# Introduction

最终结果可能经过选择、增加、替换、归还和确认。单个早期状态不能代表整个过程的结论。

# When to use

问题询问最后买了什么、最终剩多少、最终选谁或最终完成了哪种操作时使用。

# Main content

1. 对每个候选建立状态序列：提议或选择、实际取用或入车、后续撤回或替换、结账或使用确认。
2. 最终数量依据最后一次有效状态变化，明确处理额外添加又退回的物品。重叠摘要不产生额外增减。
3. 某条局部记录没有“买了”一词时，继续追踪该物品的入车、结账和交易完成关系；同时，建议或持有本身也不能单独证明购买。
4. 最终选择只纳入决策窗口最后修订后的明确承诺。先前消费、习惯偏好、含糊附和及后来行为不能自动增加当时选择人数。
5. 对操作结果读取动作及成功确认。计划付款、展示界面、实际完成和失败后换方式分别记录。
6. 完成标准保持与问题一致，例如放到垃圾桶旁或盖上并不满足投入桶内，送达地点也不等于已经交到目标人手中。
