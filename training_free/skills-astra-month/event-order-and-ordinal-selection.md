# Introduction

排序需要每个候选实际发生的证据；序数还需要覆盖所有更早的合格事件。

# When to use

问题询问顺序、第一件事、最后一次、第几次，或第 n 次动作的属性时使用。

# Main content

1. 明确排序所用里程碑：开始、首次参与、实际放置、成功领取或完成。计划、物体已在场和提到事件，均不同于相应动作的发生。
2. 独立定位每个候选，记录时间区间、主体、动作及来源，再按题目所需里程碑排序。
3. 首次或第 n 次问题要检查锚点后的连续早期记录及候选前一窗口。不要将第一个有名字、画面最清楚或最显眼的事件直接定为第一或第二。
4. 跨日序数先收集并去重完整事件集合。长时间连续行为中的多个字幕行不自动增加序数。
5. 当某个动作只有间接描述时，在已知前后锚点之间检索，并针对该候选做必要的视觉核验；字面名称未命中不证明动作缺失。
6. 重叠区间或 unknown 不能支持精确先后。先解决会改变排序的边界；仍未解决则保留局部不确定性。
7. 按请求输出顺序或序数。若问第几次，单独描述一个场景并未完成回答。
