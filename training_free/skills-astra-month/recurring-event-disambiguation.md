# Introduction

相似场景经常共享物品、参与者和对话词汇。答案必须来自满足题目全部条件的同一事件。

# When to use

问题包含某天、某次、饭后、订单后、活动期间或同时等限制，且存在多个候选场次时使用。

# Main content

1. 分别定位日期、锚点、动作、对象和参与者线索，再建立场次记录。若题目要求并发行为，所有证据必须与焦点窗口重叠。
2. 对每个候选读取邻近细记录，区分计划、到达、实际进行、结束及后续活动。字面标签更相似但时间不符的候选仍应排除。
3. 将多个锚点限制在同一事件序列内。不要将早期提议与晚间另一场活动的完成记录拼成持续时间。
4. “刚刚之后”优先检查完成后的局部连续记录；题目只要求“之后”且没有立即性限制时，后续相关行为可能更晚，不能停在第一个看似合理的交接。
5. 若事件延长、暂停或重新开始，检索续段再判断结束与因果。活动中途的界面切换、暂离或部分完成不必然是终点。
6. 已定位场次中的姓名、衣着、品牌、人数和物品属性不能从另一场同类活动移植。记录仍冲突时保留候选差异。
