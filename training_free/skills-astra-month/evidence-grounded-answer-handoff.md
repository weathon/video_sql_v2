# Introduction

最终答案应从已核实的证据记录生成，并直接满足题目要求的输出形式。

# When to use

检索已经足够、准备回答，或多次工具调用后需要整合结论时使用。

# Main content

1. 逐项确认答案有对应的时间、主体、对象和关系证据。不要仅凭工具生成的最终句子或评分通过就认可其依据。
2. 检查输出类型：序数题给序数，顺序题给顺序，多选题给完整集合，总额题完成求和，人物题采用题目要求的外观或第一人称参照。
3. 保留必要的名称限定、原文、材料、单位和关系；只到大类的证据不支持更细品牌或身份。
4. 不让最后一次空查询、无关工具输出或错误消息覆盖已支持结论。提交调查结果，而不是直接转发最近一次返回文本。
5. 未决视觉或身份只影响依赖它的部分。不要把 unknown 写成否定，也不要为补齐答案虚构端点、金额、次数或因果。
6. 直接证据与参考标签冲突时保留冲突，不为匹配预期改造证据。同一答案获得不同评分，也不能推出检索方法或姓名映射的优劣。
7. 删除不影响所问事实的背景、猜测姓名和额外情节。答案成立后不再通过无关检索增加未请求细节。
