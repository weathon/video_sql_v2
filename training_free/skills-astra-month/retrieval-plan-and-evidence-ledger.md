# Introduction

有效检索需要明确待证明的关系，并持续区分候选线索、直接证据和未解决问题。

# When to use

开始调查、出现多个相似事件，或已有大量结果却仍无法形成答案时使用。

# Main content

1. 将问题拆为时间范围、事件条件、人物角色、对象及所需输出。特别区分动作次数、独立物品数、某时刻库存、参与人数和金额。
2. 从最独特的动作、原话、物品或结果开始检索。语义搜索用于发现候选，局部原始记录用于确认关系；粗摘要用于导航，细记录用于解决具体分歧。
3. 为每项待回答内容记录候选时间、来源 ID、支持的事实、缺失的关联及冲突。多分支调查保留简短笔记，避免后续摘要丢掉已发现的线索。
4. 将下一次调用用于填补一个明确缺口。视觉属性缺失时定位后看图；原话或操作记录已充分时直接使用文本。
5. 新结果只有在提供更直接或更匹配的证据时才改变结论。空查询、QA 的笼统判断以及更晚出现的相似事件，不应覆盖已经核实的局部事实。
6. 所需关系和答案单位都已建立后停止扩展。调用更多工具或取得相同评分，本身不证明证据更好。
