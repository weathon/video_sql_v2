# Introduction

某一状态的库存与整个过程中的转移次数不同。计数需固定时刻，并枚举同一状态中的独立物品。

# When to use

问题询问离开时携带多少、桌面最终有多少、某房间中有多少设备等静态或瞬时数量时使用。

# Main content

1. 固定题目要求的瞬间或终态。涉及第一间房间或门槛时，先确认字面边界，不把第一间改成第一间有目标物的房间。
2. 选择几个紧邻且足够完整的视角，按桌面、容器、行列或携带者逐项列出，追踪视角变化中的同一物品。
3. 行列结构只有在各位置清楚时才可相乘。图案种类、放置动作和已装饰子集不能替代全部件数。
4. 第一人称画面可能没有拍到摄像者携带的物品。仅在同一过渡时刻有明确持有证据时补入，并避免与可见物重复。
5. 不把不同时间的每人数量相加，不把转移过程中的不同持有者算成不同物品。
6. 若题目实际询问整个过程搬运了多少，则改用实例追踪与事件台账；单个出发或到达画面可能不足。
