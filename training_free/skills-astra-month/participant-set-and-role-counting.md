# Introduction

在场、属于某组、实际参与、最初加入和持续工作至结束，是不同资格条件。

# When to use

问题询问活动参与人数、谁缺席、谁坚持到最后，或某个转场中有哪些人时使用。

# Main content

1. 明确人员资格和时间口径：某一时刻在场、初始队伍、全过程参与过的并集，或持续参与直至完成。
2. 优先检查与该场活动及该角色对应的明确名单或人数声明。房间中可见人数不自动等于活动参与者人数。
3. 初始人数与总参与人数分别核验。全过程总数要合并早期与后来加入者；末帧不能覆盖全程成员集合。
4. “坚持到结束”需要完成阶段持续执行任务的证据。旁观者、短暂返回者、摄影者和导演不因最后在场就获得参与资格。
5. 到达或离开问题检查真实过界瞬间，并纳入此前已加入队伍的人；最早接近画面中尚未出现，不证明最终没有一起进入。
6. 比较群体与周围人员时保留集合方向，区分成员、随行者和司机等角色。任务组成员关系也不等于每次局部互动都共同在场。
