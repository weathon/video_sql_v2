# Introduction

视觉模型的回答需要由实际返回帧支撑。重复调用给出不同数字或标签时，不能通过挑选一个答案消除冲突。

# When to use

视觉结果影响结论，尤其是计数、短暂动作、可见身份或细小文字时使用。

# Main content

1. 查看返回的证据截图和源时间，确认场景、对象及时间窗口正确。截图不包含所称物体、来自更早场景，或时间未覆盖所称动作时，该结论没有相应视觉依据。
2. 将 answered、unknown、明确未观察到及工具错误分开。unknown 和错误不能支持否定，也不能填补动作或数量。
3. 冲突时检查是否采样了不同时间、不同对象、不同动作口径，或不同颜色部位。把下一次检查缩到真正有分歧的转换点，并中性提问。
4. 不对冲突计数取平均，不把重叠窗口总数相加，也不选最接近预期或参考答案的结果。
5. 明确局部文本与清晰视觉证据各自证明什么。含糊或未覆盖动作的视觉调用不推翻明确文本；同样，粗字幕也不覆盖已清楚观察到的动作差异。
6. 无法解决的冲突继续标为未决。若问题的其他部分已有充分证据，可保留那些结论，不扩大未知范围。
