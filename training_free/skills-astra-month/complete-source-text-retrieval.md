# Introduction

检索摘要和长文本预览可能省略答案所需的限定词、后半句、否定或后续确认。

# When to use

结果被截断、宽查询溢出、QA 说未建立某事实，或答案需要精确名称和原话时使用。

# Main content

1. 先获取紧凑候选信息：真实 ID、时间、粒度和相关短文本。随后按已返回 ID 或狭窄时间范围读取关键行及相邻行。
2. 若长单元格仍被缩短，读取包含线索的局部文本切片，并继续覆盖可能包含结论的后半段。不要将截断处当成句子结束。
3. 对话跨行时同时读取前提、回答、修正和确认；保留决定答案的限定词、材料、数量关系及否定。
4. 宽 SQL 或 QA 输出失败时，按时间或候选 ID 拆分。错误输出没有提供证据，重新执行同样的大查询也不会弥补缺口。
5. QA 的“不足以确定”只描述它所处理的材料和解释。若已存在明确候选，检查原始行再决定是否缺失。
6. 不猜测 episode ID。猜测 ID 未命中时使用已知时间窗口查找真实记录。
7. 获得直接、完整且足够的文本后停止扩大检索；额外视觉调用仅用于仍缺失的可见条件。
