# Introduction

持续时间由所测事件及端点定义决定。摘要覆盖范围、首次提及、参与者估计和实际活动时长可能不同。

# When to use

问题询问多久、何时开始或结束、两个事件相隔多久，或要求选择近似时长选项时使用。

# Main content

1. 先明确所测对象：命名注释事件、实际操作、特定工具使用、完成订单后的等待，或某场所内的停留。
2. 独立检索两端。检查局部细记录中的开始、成功完成、首次到达或实际离开，不以较早的计划、打开应用、交通讨论、付款或收拾自动替代。
3. 问题指向某个命名注释事件时，可使用其明确声明的端点；问题要求实际物理活动时，则依据实际动作边界。后续相似动作不自动延长一个已定义事件。
4. 使用粗摘要定位，避免将 `10min` 等粒度标签解释为持续时间。分钟分桶的主题事实可能晚于事件实际开始。
5. 先换算时间并计算，再对照选项。明确区分实测区间、对话中的估计和最低时长；工具的预计耗时不等于已测使用时间。
6. 端点只确定到一个窗口时保留相应精度。若所有有依据的端点都落在同一答案范围，可据此作近似选择，无需制造更精确的时间。
7. 仅在未确定的物理边界会影响答案时，增加局部视觉核验。
