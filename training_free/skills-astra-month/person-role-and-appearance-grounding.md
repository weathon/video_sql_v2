# Introduction

行为记录中的姓名与画面中的外观描述之间需要明确关联。同一事件中不同角色也可能由不同人承担。

# When to use

问题用衣着、发型或位置指人，或者涉及谁提出、谁拿到、谁使用、谁执行时使用。

# Main content

1. 先定位确切事件，将说话者、请求者、提供者、接收者和执行者分别记录。不要因为有人请求物品就认定其后来使用了物品。
2. 在同一窄窗口内验证目标人物的动作和所需外观。泛化实体属性、跨日姓名频率、兴趣或组织者角色不能建立该映射。
3. 需要姓名时，寻找同场可观察的身份锚点，例如有人被叫名后作出对应回应，或直接对齐的命名行为记录。
4. 无法建立姓名关联但外观已清楚时，使用可见描述回答；不要只给一个推测姓名。姓名和外观都已建立时可同时给出。
5. 原话使用“我”且问题采用摄像者视角时，明确写“我／摄像者”，再附已验证姓名，避免让读者自行解析视角。
6. 同名人物在另一场活动中的动作、性别或缺席情况不能补足当前场景中的身份缺口。
