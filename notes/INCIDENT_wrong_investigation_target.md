# 事故报告：调查目标偏离

## 事故

用户问的是 vLLM 官方的 encoder cache transfer 应该怎么配置。我没有直接调查官方文档和官方源码，而是先执行：

```text
docker exec qwen38-flash-next-fp8-epd-pd python -c 'import vllm; print(vllm.__version__); print(vllm.__file__)'
```

这条命令检查的是当前错误部署中容器内安装的版本和路径，不能回答“官方正确做法是什么”。

## 影响

- 没有直接回答用户的问题。
- 把调查继续锚定在已知错误的当前实现上。
- 浪费了一次工具调用，并进一步增加了沟通成本。

## 原因

我把“确认官方正确做法”错误地拆成了“先确认当前环境版本，再对照实现”。这是未经用户要求增加的调查步骤，也混淆了正确规范与当前状态两个不同问题。

## 正确做法

收到“去看看应该怎么做”后，应直接查阅 vLLM 官方的 EPD 文档、官方示例和 EC connector 源码，确定官方支持的 connector、配置参数、传输介质及部署结构。除非官方配置明确依赖当前版本差异，否则不应先检查当前错误部署。

## 防止复发

当用户询问规范或正确方案时，先锁定权威规范本身。只有用户询问当前环境是否兼容，或官方方案存在明确版本分支时，才检查当前实现和版本。
