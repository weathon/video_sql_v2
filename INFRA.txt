Current formal infrastructure (no encoder disaggregation)

The main Qwen service runs vision encoding, prefill, and decode together on
physical GPUs 0,2,5,7. The embedding service runs on physical GPU 4. Both
containers use the project bridge network. Do not start containers with
`--rm`; stop them after the run, inspect their logs, and remove them manually.

Create the project network once:

docker network create video-sql-v2

Main Qwen/Qwen3.8-Flash-Next-FP8 service:

docker run --name qwen38-flash-next-fp8 \
    --network video-sql-v2 \
    --gpus '"device=0,2,5,7"' \
    --shm-size=32g \
    -p 8000:8000 \
    -e HF_HOME=/hf_cache \
    -e VLLM_ALLOW_LONG_MAX_MODEL_LEN=1 \
    -v /raid/huggingface:/hf_cache \
    vllm/vllm-openai:qwen38-flash-next \
    Qwen/Qwen3.8-Flash-Next-FP8 \
    --host 0.0.0.0 \
    --port 8000 \
    --max-model-len 314573 \
    --hf-overrides '{"text_config":{"rope_parameters":{"mrope_interleaved":true,"mrope_section":[11,11,10],"rope_type":"yarn","rope_theta":10000000,"partial_rotary_factor":0.25,"factor":1.2,"original_max_position_embeddings":262144}}}' \
    --max-num-seqs 24 \
    --gpu-memory-utilization 0.90 \
    --enable-prefix-caching \
    --no-enable-flashinfer-autotune \
    --tensor-parallel-size 4 \
    --enable-auto-tool-choice \
    --tool-call-parser qwen3_coder \
    --reasoning-parser qwen3 \
    --speculative-config '{"method":"mtp","num_speculative_tokens":2}' \
    --kv-transfer-config '{"kv_connector":"SimpleCPUOffloadConnector","kv_role":"kv_both","kv_connector_extra_config":{"cpu_bytes_to_use_per_rank":236223201280,"lazy_offload":false}}' \
    --default-chat-template-kwargs '{"enable_thinking":true,"preserve_thinking":true}'

Qwen/Qwen3-VL-Embedding-8B service:

docker run --name egolife-qwen3-vl-embedding-8b \
    --network video-sql-v2 \
    --gpus '"device=4"' \
    --shm-size=8g \
    -p 8013:8000 \
    -e HF_HOME=/hf_cache \
    -v /raid/huggingface:/hf_cache \
    -v /raid/wg25r/video_sql_v2:/workspace/video_sql_v2:ro \
    vllm/vllm-openai:qwen38-flash-next \
    Qwen/Qwen3-VL-Embedding-8B \
    --served-model-name qwen3-vl-embedding-8b \
    --runner pooling \
    --host 0.0.0.0 \
    --port 8000 \
    --gpu-memory-utilization 0.45 \
    --mm-processor-cache-gb 0 \
    --trust-remote-code \
    --allowed-local-media-path /workspace/video_sql_v2/data/pilot/clips \
    --renderer-num-workers 4 \
    --max-num-batched-tokens 32768 \
    --media-io-kwargs '{"video":{"video_backend":"qwen3_vl","backend":"torchcodec","fps":2,"num_frames":-1,"seek_mode":"approximate","num_ffmpeg_threads":4}}'

Stop after the run:

docker stop qwen38-flash-next-fp8 egolife-qwen3-vl-embedding-8b

After debugging and log inspection, remove the stopped containers manually:

docker rm qwen38-flash-next-fp8 egolife-qwen3-vl-embedding-8b
